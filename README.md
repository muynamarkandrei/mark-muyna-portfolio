# Mark's IT Compass

1. PROJECT OVERVIEW

Build a professional personal portfolio website for Mark Andrei B. Muyna, a BS Information Technology student and aspiring early-career IT professional.

The website should present him as a technically curious, practical, and continuously learning IT professional with real-world experience from his practicum/OJT, academic project work, and self-directed networking labs.

The portfolio should not exaggerate his experience or present him as a senior engineer, cybersecurity professional, network engineer, or experienced software developer.

The central professional identity should communicate:

Someone who enjoys understanding why technology fails, troubleshooting practical problems, helping users, and learning how computers, applications, devices, and networks work together.

The website should feel like a professional Corporate IT portfolio, not a flashy developer showcase.

Design the website primarily for:
