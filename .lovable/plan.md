# Professional portfolio refinement

## Goal
Refine the existing portfolio into a focused, recruiter-friendly early-career IT Support and Infrastructure portfolio without redesigning it or overstating experience.

## Planned changes
- Simplify the main navigation to Home, About, Experience, Projects, Skills, Resume, and Contact. Keep Gallery and Case Studies available from Experience.
- Tighten the opening and About copy while preserving the current identity, troubleshooting mindset, and prominent 500-hour practicum proof.
- Make Experience the clearest centerpiece, retaining the verified employer, team, dates, hours, supervised intern context, and six practical work areas.
- Add a concise “What I Can Help With” section translating verified skills into realistic entry-level workplace tasks.
- Keep all six case studies and standardize their Problem, Investigation, Cause, Solution, Result, and What I Learned presentation.
- Refine the Capstone wording as an academic systems project, retain supported contributions, and keep Cisco labs explicitly fundamentals-level.
- Strengthen Skills hierarchy and group Certifications by relevance while keeping credential links functional.
- Remove redundant gallery content, retain distinct work stages, and improve captions only where the image and existing records support the wording.
- Apply small consistency and mobile-readability improvements to spacing, cards, buttons, and content layout without changing the visual identity.

## Technical details
- Reuse the existing semantic color and typography system.
- Keep `/gallery` as a separate page and link to it from Experience.
- Preserve the existing one-page homepage structure and TanStack routes.
- Add reduced-motion behavior and avoid additional decorative animation.
- Verify metadata, type safety, all links, and desktop/mobile rendering after the edits.

## Accuracy guardrails
- No new metrics, achievements, responsibilities, technologies, or senior titles.
- Preserve conservative intern-under-supervision language.
- Keep programming secondary to IT Support, troubleshooting, networking, and infrastructure fundamentals.
